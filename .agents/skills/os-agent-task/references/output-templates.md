# 输出模板

只保留有内容的栏目。结论先行，避免重复任务背景。低风险任务保持短；高风险任务输出必要的全局位置、不变量和证据边界，但不展开内部推理过程。

## contract

```text
推荐模型：<model>
备选模型：<仅必要时>

$os-agent-task <mode>

目标：<结果目标>
验收：<机器可判定条件>
本轮特殊约束：<只写会改变结果的边界>
```

高风险任务可在“本轮特殊约束”中精简加入：状态/不变量、commit/rollback、生命周期测试和根因不足时只审计。

## audit

```text
结论：<建议实现/不建议/证据不足>

全局位置：
- 当前阶段/门禁：...
- 问题类型：core / lifecycle / tooling / performance / docs

症状、首错与根因状态：
- 症状：...
- 首个真实错误：...
- 根因：<已确认/高置信/目前无法确认>

被破坏的不变量：
- ...

关键证据与调用链：
- ...

替代假设与证伪：
- ...

方案范围与风险：
- 最小接入位置：...
- 代价/失效场景：...

最关键下一步：...
```

低风险审计可省略无内容栏目。

## implement

```text
结论：<代码已实现并通过短验证/证据不足/未完成>

全局位置与根因依据：
- ...

修改：
- <文件：行为变化>

状态/生命周期：
- <仅高风险任务；合法转移、commit/rollback、默认关闭>

验证：
- <命令或 target：PASS/FAIL>

未验证：
- <真实 server、模型、clean HEAD 或用户长测>

未确认事项与风险：
- ...

git diff --stat：...
git status --short：...

工程账本影响：<仅在需要时>
最关键下一步：...
```

## review

```text
结论：<通过/有非阻塞问题/有阻塞问题/证据不足>

全局位置：
- ...

被尝试推翻的核心假设：
- ...

阻塞问题：
- <文件/函数/不变量/影响>

非阻塞问题：
- ...

已有证据：
- ...

缺失证据：
- ...

工程账本影响：<仅在需要时>
最小下一动作：...
```

## review-fix

```text
结论：<代码修复已完成，真实路径尚未验证/阻塞仍存在/证据不足，未修改/阻塞已由对应真实证据关闭>

- 阻塞项 A → 根因/不变量 ... → 修改 ... → 短验证 ... → 尚缺证据 ...
- 阻塞项 B → 根因/不变量 ... → 修改 ... → 短验证 ... → 尚缺证据 ...

未处理：
- <非本轮范围、证据不足或审查结论不成立>

工程账本影响：<仅在需要时>
当前是否可进入下一验证：<是/否>
```

```text
文件：
- ...

事实记录与 verdict authority：
- runner：...
- parser：...
- Harness：...

参数与输出：
- ...

PASS/FAIL 规则：
- ...

静态/短测：
- ...

用户正式执行：
<命令>

结果提取：
<命令>

工程账本影响：<仅在形成正式协议或结果入口时>
```

## memory

```text
结论：<已初始化/账本一致/已更新/有冲突/证据不足>

文件：
- <文件：创建或更新内容>

依据：
- <源码、commit、diff、测试或实验证据>

未写入：
- <因证据不足拒绝记录的事项>

```
