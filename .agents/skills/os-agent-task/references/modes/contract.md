# contract

目标：输出可直接复制的最短完整任务契约，不修改仓库。

只读取 PROJECT_STATE 和会改变任务边界的 1–2 个相关章节；不要为了写提示词恢复全部历史。

输出格式：

```text
$os-agent-task <mode>

推荐模型：<仅需要时>
目标：...
验收：...
本轮特殊约束：...
```

只写目标、机器可判定验收和本轮新增边界。固定仓库背景、Git 禁止项、输出格式、长测分工由 Skill 承担，不重复。高风险任务用一段压缩写清状态/不变量、commit/rollback 和生命周期测试；根因不明时指定 `audit`，不直接生成施工方案。
