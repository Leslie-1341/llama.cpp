what is better to CHANGE COLUMN for almost all columns of the table or create a new table and backfill with INSERT, SELECTIt depends on the specific circumstances of the task at hand.If you want to change the data type or size of a column, and you want to do this for almost all columns of a table, then using the ALTER TABLE ... CHANGE COLUMN statement would be the most efficient way to accomplish this.However, if you're looking to make more extensive changes to the table's structure, or you want to rename many columns at once, creating a new table and backfilling it with an INSERT INTO ... SELECT statement might be a better option. This way you can make sure the new table has the structure you want and all the data is populated into it.Overall, it's generally easier to add columns and to change the data types of existing columns using the ALTER TABLE statement. While adding and dropping columns from a table that has a lot of data can be time-consuming and may require significant amounts of storage space.It's always good to test your changes in a test environment first and make sure that it does not break any app or code that is dependent on it.
